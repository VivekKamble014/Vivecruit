# 🚀 PayU Integration Guide for ViveCruit

## 📋 Prerequisites

1. **PayU Account**: Sign up at [payumoney.com](https://payumoney.com)
2. **Business Documents**: PAN, Aadhaar, Bank Account details
3. **Website**: Your domain should be live and functional
4. **SSL Certificate**: Required for secure transactions

## 🔧 Step-by-Step Setup

### 1. Create PayU Account

1. Go to [payumoney.com](https://payumoney.com) and click "Sign Up"
2. Fill in your business details:
   - Business name: "ViveCruit" or your company name
   - Business type: Technology/SaaS
   - PAN number
   - Bank account details
3. Complete KYC verification
4. Wait for account activation (usually 24-48 hours)

### 2. Get API Keys

1. Login to PayU Dashboard
2. Go to **Settings** → **API Keys**
3. Generate new API key pair
4. Copy both **Merchant Key** and **Salt**

### 3. Environment Variables Setup

Add these to your `.env.local` file:

```env
# PayU Configuration
PAYU_KEY=your_merchant_key_here
PAYU_SALT=your_salt_here
NEXT_PUBLIC_PAYU_KEY=your_merchant_key_here
NEXT_PUBLIC_PAYU_SALT=your_salt_here

# Base URL for callbacks
NEXT_PUBLIC_BASE_URL=http://localhost:3000

# Database Configuration (if not already set)
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
```

### 4. Database Setup

Run the SQL script in your Supabase dashboard:

```sql
-- Add billing-related columns to Users table
ALTER TABLE public."Users" 
ADD COLUMN IF NOT EXISTS plan VARCHAR(50) DEFAULT 'Free',
ADD COLUMN IF NOT EXISTS plan_updated_at TIMESTAMP WITH TIME ZONE,
ADD COLUMN IF NOT EXISTS payment_id VARCHAR(255),
ADD COLUMN IF NOT EXISTS order_id VARCHAR(255),
ADD COLUMN IF NOT EXISTS interviews_created INTEGER DEFAULT 0,
ADD COLUMN IF NOT EXISTS interviews_limit INTEGER DEFAULT 1;

-- Create payments table to log all transactions
CREATE TABLE IF NOT EXISTS public.payments (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT now(),
    user_email VARCHAR(255) NOT NULL,
    user_id BIGINT,
    plan_name VARCHAR(50) NOT NULL,
    payment_id VARCHAR(255) NOT NULL,
    order_id VARCHAR(255) NOT NULL,
    amount INTEGER NOT NULL,
    status VARCHAR(50) NOT NULL DEFAULT 'pending',
    payment_date TIMESTAMP WITH TIME ZONE,
    currency VARCHAR(10) DEFAULT 'INR',
    CONSTRAINT payments_pkey PRIMARY KEY (id)
);

-- Create index for better query performance
CREATE INDEX IF NOT EXISTS idx_payments_user_email ON public.payments(user_email);
CREATE INDEX IF NOT EXISTS idx_payments_payment_id ON public.payments(payment_id);
CREATE INDEX IF NOT EXISTS idx_users_plan ON public."Users"(plan);

-- Update existing users to have Free plan
UPDATE public."Users" 
SET plan = 'Free', interviews_limit = 1 
WHERE plan IS NULL;
```

## 🔒 Security Best Practices

### 1. Hash Verification
- Always verify payment hash on server
- Use SHA512 for hash generation
- Verify all payment parameters

### 2. Environment Variables
- Never commit API keys to version control
- Use different keys for test and production
- Rotate keys regularly

### 3. Error Handling
- Handle payment failures gracefully
- Log all payment attempts
- Provide clear error messages to users

## 📱 Webhook Setup (Optional but Recommended)

### 1. Create Webhook Endpoint

Create `/api/payu-webhook`:

```javascript
import { NextResponse } from 'next/server';
import crypto from 'crypto';

export async function POST(req) {
  try {
    const formData = await req.formData();
    const txnid = formData.get('txnid');
    const status = formData.get('status');
    const hash = formData.get('hash');
    
    // Verify webhook hash
    const key = process.env.PAYU_KEY;
    const salt = process.env.PAYU_SALT;
    const hashString = `${salt}|${status}|||||||||||${txnid}|${key}`;
    const calculatedHash = crypto.createHash('sha512').update(hashString).digest('hex');
    
    if (calculatedHash !== hash) {
      return NextResponse.json({ error: 'Invalid hash' }, { status: 400 });
    }
    
    // Handle different webhook events
    switch (status) {
      case 'success':
        // Payment successful
        break;
      case 'failure':
        // Payment failed
        break;
      default:
        console.log('Unhandled status:', status);
    }
    
    return NextResponse.json({ received: true });
  } catch (error) {
    console.error('Webhook error:', error);
    return NextResponse.json({ error: 'Webhook processing failed' }, { status: 500 });
  }
}
```

### 2. Configure Webhook in PayU Dashboard

1. Go to **Settings** → **Webhooks**
2. Add webhook URL: `https://yourdomain.com/api/payu-webhook`
3. Select events: `payment.success`, `payment.failure`
4. Save webhook configuration

## 🔍 Troubleshooting

### Common Issues

1. **"Invalid Hash"**
   - Check if you're using correct test/live keys
   - Verify hash generation algorithm
   - Check parameter order in hash string

2. **"Payment Failed"**
   - Check PayU dashboard for error details
   - Verify webhook configuration
   - Check server logs for errors

3. **"Order Creation Failed"**
   - Verify amount format
   - Check currency is set to 'INR'
   - Verify API key permissions
